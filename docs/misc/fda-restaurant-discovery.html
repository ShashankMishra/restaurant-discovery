  • [ID] Same id as the old system, so copies from SQL don’t create duplicates.
  • [NEST] Rating and flags stay on the restaurant. Always shown together.
  • [GEO] Location is a point. Longitude first.

--next-to-old-system

Beside the old backend

flowchart LR
  Partner[Partner_site]
  Old[Old_backend]
  SQL[(SQL)]
  Copy[Copy_restaurant_rows]
  New[This_API]
  Mongo[(Mongo)]
  Partner --> Old --> SQL
  SQL --> Copy --> Mongo
  New --> Mongo
SQL stays the place partners write. Mongo is what search reads. If SQL is ahead of Mongo, replay the copy. Don’t write both in one request unless there’s a queue in between.

flowchart TB
