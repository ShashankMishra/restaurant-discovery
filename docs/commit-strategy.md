# Commits

Conventional Commits, the example from the brief.

Format: `type: imperative summary` — no period, under 72 chars.

Types: `feat`, `fix`, `docs`, `test`, `chore`.

1. `chore: bootstrap Quarkus 3 service and Compose Mongo`
2. `feat: add the restaurant document model`
3. `feat: ingest Zomato restaurants and create indexes`
4. `feat: add restaurant create and get-by-id`
5. `feat: list restaurants with filters, sort, and geo`
6. `fix: reject distance queries that omit coordinates`
7. `fix: count nearby results with the same distance limit`
8. `feat: parse natural-language restaurant search`
9. `feat: add a page to search, browse, and add restaurants`
10. `test: cover discovery endpoints with QuarkusTest`
11. `docs: add architecture, ADRs, and setup`

No secrets, no `build/` or `.gradle`.
